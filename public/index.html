Preferenze applicazione

Impostazioni

La versione Cloudflare usa servizi gratuiti e non richiede chiavi API private.

Hosting

Interfaccia statica su Cloudflare Pages con API serverless per cercare release.

Compatibilità Minecraft

La ricerca del catalogo è configurata per Minecraft 1.21.1. Devi selezionare il loader desiderato nella pagina Minecraft Mods.

Cloudflare non può leggere né modificare i file sul tuo PC. Dopo aver scaricato un JAR compatibile, installalo nel profilo corretto sul computer.

Costi e limiti

Nessuna API a pagamento, abbonamento esterno o chiave segreta. La Function chiama l’API pubblica Modrinth. Cloudflare Pages offre hosting statico gratuito; l’esecuzione serverless è soggetta ai limiti del piano gratuito e Modrinth applica i propri limiti di richiesta.

Consulta sempre le condizioni aggiornate dei due servizi. Il catalogo non installa automaticamente mod nel tuo Minecraft.

Fogpacks completo per Windows

Vuoi conservare anche il rilevamento del profilo Minecraft, l’installazione di JAR locali, gli import, il workspace e i backup? Queste funzioni richiedono accesso al computer e sono mantenute nella versione Python locale inclusa nel pacchetto.

Scarica la versione locale completa

Usa il file ZIP su un PC Windows con Python 3.11 o successivo (consigliato Python 3.13). Non servono pacchetti Python aggiuntivi.
