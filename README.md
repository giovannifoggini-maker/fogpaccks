# Fogpacks — Cloud Edition + Local Edition

Questo pacchetto mantiene sia la versione web per Cloudflare Pages sia la versione locale completa per Windows.

- `public/`: app web con Mod Maker, cataloghi, esportazione nel browser e pagina Impostazioni.
- `functions/`: API serverless su Cloudflare Pages per cercare release pubbliche su Modrinth.
- `local-edition/`: versione Python completa con launcher e asset, per operazioni su file e profili Minecraft locali.
- `public/downloads/Fogpacks_Local_Complete.zip`: archivio della versione locale scaricabile anche dalla pagina web.

Non sono richiesti API a pagamento, token privati o pacchetti Python aggiuntivi. Consulta `ISTRUZIONI-CLOUDFLARE.txt` per il deployment e i limiti della versione cloud.

La ricerca online e l'hosting dipendono dalle quote gratuite e dalle condizioni aggiornate dei rispettivi servizi. La Cloud Edition non installa direttamente i JAR sul PC; per questo è mantenuta anche la versione locale.
